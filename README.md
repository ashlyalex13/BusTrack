# BusTrack

Sistema de gestion de rutas, viajes y venta de tiquetes de transporte terrestre.

## Objetivo

Desarrollar un sistema que permita consultar horarios, administrar viajes y gestionar la venta y verificacion de tiquetes.

## Tecnologias

- Python
- FastAPI
- MySQL 8
- SQLAlchemy
- React y Vite (frontend)

## Estructura del proyecto

- `backend/`: API y logica del servidor.
- `frontend/`: interfaz de usuario.
- `docs/`: documentacion y diseño de la base de datos.

## Estado del proyecto

En desarrollo.

## Instalacion y ejecucion

Las instrucciones se actualizaran a medida que se configure el entorno y se implementen los modulos.
